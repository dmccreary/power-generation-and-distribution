# Utility Rates and Project Economics

## Summary

This chapter connects facility electrical behavior to utility bills and project decisions. Students analyze energy, demand, time-of-use, and power-factor charges, then apply capital cost, operating cost, incentives, simple payback, return on investment, and net present value. They will be able to compare alternatives using both utility-rate and economic evidence.
