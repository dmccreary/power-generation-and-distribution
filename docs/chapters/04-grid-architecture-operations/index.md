# Grid Architecture and System Operations

## Summary

This chapter places individual electrical systems within the larger interconnected grid. It explains interconnections, balancing authorities, regional transmission organizations, reliability, frequency control, supply-demand balance, generation roles, reserves, and load following. Students will be able to describe how grid operators coordinate generation and load across large regions.
