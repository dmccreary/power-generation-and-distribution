# Distribution Performance and Reliability

## Summary

This chapter focuses on measuring and improving distribution-system performance. Students apply automation, Volt-VAR control, power-factor correction, capacitor sizing, outage analysis, SAIDI, SAIFI, CAIDI, redundancy, single-point-of-failure analysis, and resiliency principles. They will be able to interpret reliability data and recommend targeted system improvements.
